# Лицензии используемых источников данных

| Источник | Репозиторий | Лицензия | Назначение и ограничения |
|---|---|---|---|
| CoDocBench | https://github.com/kunpai/codocbench | Отсутствует явная лицензия (Public research repository, академическое цитирование через CITATION.cff) | Используется для извлечения положительных пар связанных изменений кода и docstring. Исходные файлы датасета не коммитятся в git-репозиторий FreshDoc, обрабатываются локально. В репозиторий включаются только производные таблицы признаков. |
| DeepSeek deepseek-flash (DeepSeek-V4.1-Flash, reasoning_effort=max) | DeepSeek API (api-docs.deepseek.com, сверено 13.10.2026) | Отдельного запрета на обучение по выходам в API-доках нет; использование учебное, некоммерческое | Генератор P1/P2 для synth_llm основной партии (FD-11). Выходы используются для обучения. Пилот FD-10 (12.10.2026) исторически делался на Muse Spark 1.3 через субагентов — только пилот, в основную партию не входит. |
| Gemini 3.8 Flash (high) | Провайдер модели | Использование учебное, некоммерческое (проверка команды 12.10.2026) | Зарезервирована только как судья M3 (FD-22). Для отбора и фильтрации данных не используется. |
