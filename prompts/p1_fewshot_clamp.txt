Few-shot example for the P1 (behavior change) prompt. Append the example below to
prompts/p1_behavior.txt (before the "Return JSON" line) only if the pilot accept
rate is below 40% (FD-10, step 5).

Input function:
def clamp(value, low=0, high=100):
    """Limit value to the range [low, high].

    Values above high are returned as high.
    """
    return max(low, min(value, high))
