  упоминания словом; пул тот же (9158), seed 42, cap 30000.
- Генерация: попыток 342870, принято 44143 (pos 17762 / neg 26381);
  отклонено: none 59537, страховка 807. Выход
  `synth_ast_v2.parquet` — **29515 пар** (pos 15000 / neg 14515,
  дедуп `pair_id` 485).
- Приёмка grep-ом: прозовых переименований — **0/3130** (было 975/3876);
  добавленных `if not X` — 0 по всем типам; `None ==` в removed — 0;
  утечек test-пула 0, `pair_id` уникален, метка согласована.
- Выборка: `reports/synth_ast_v2_manual30_r5.csv` — **30 строк**
  (сид 11, без пересечения с r4, только новые хэши; квоты 5/5/5/4/4/4/3).

## Раунд 4 (макс. качество, актуальный)

- Причины (ревью FD-09): (1) `param_added` мёртв по построению — 99,3%
  неиспользуемых в v1, 17,9% v2; (2) `return_changed` наполовину
  truthiness-гарды (`if not X` мёртв на opaque-объектах, падает на
  Series/DataFrame); (3) `param_removed` давал `if None == ...` /
  `if not True:`; (4) фильтр `test_` только по имени пропускал ~3%
  хелперов из test-файлов.
- Фиксы (тот же seed 42, cap 30000, условия мутаций не ослаблялись):
  - `mut_param_added`: продвижение магической константы в параметр —
    литерал в теле заменяется новым kwonly-параметром с тем же
    значением-дефолтом (поведение для дефолтных вызовов идентично);
    без совпадения — пропуск, мёртвых параметров больше нет.
    Локально связанные имена не предлагаются; дефолты сигнатуры,
    декораторы и литеральные куски f-строк не трогаем.
  - `mut_return_changed`: всегда `if X is None` (ветка `if not X` удалена).
  - `mut_param_removed`: подставленный литерал в `Compare`
    (`None == ...`) или под `not` — мутация неприменима.
  - пул v2: фильтр тестовых путей (`test/`, `tests/`, `*_test.py`,
    `test_*`, `conftest.py`, `*_tests`-каталоги, якорные правила —
    `latest.py`/`contest.py` не задевает); v1 не тронут.
- Пул: `functions_pool_v2.parquet` — **9158** (v1 1474 + источник2 7684;
  отсев путей 5473, имён 11, R1 7986, дедуп внутри 116, против v1 1).
- Генерация: попыток 336911, принято 45314 (pos 18933 / neg 26381);
  отклонено: none 58111, страховка 807, синтаксис 0. Выход
  `synth_ast_v2.parquet` — **29520 пар** (pos 15000 / neg 14520,
  дедуп `pair_id` 480). Новых хэшей 24816 (84,1%).
- Приёмка grep-ом (код, не глазами): добавленных `if not X` — **0**
  по всем типам; `None ==` в removed — 0; `not True/False` в removed —
  3 предсуществующих (sklearn `enet_path`, есть и в `code_old`),
  добавленных 0; `is None` в return — 1461/1461; `is None`-гард в
  exception-диффах — 5162/5291 (остальное — ветка замены типа без
  гарда); `param_added` с живым использованием — 2573/2573 (пример:
  `','.join(symbol)` → `sep.join(symbol)` при `*, sep: str=','`).
  Утечек test-пула 0, `pair_id` уникален, метка согласована с типом,
  фильтры R1 на выходе держатся.
- Выборка: `reports/synth_ast_v2_manual30_r4.csv` — **30 строк**,
  только новые хэши, стратификация 5/5/5/4/4/4/3
  (added/renamed/none/removed/return/exc/default), `verdict`/`comment`
  пустые — на разметку человеку. Бар FD-08: ≥27/30 (90%).
- Разметка раунда 4 (человек, сверено):
  **28/30 разумно (93,3%)**. Оба неразумных — `param_renamed` с
  прозой без секции параметров (`entry` в «a config entry»,
  `value` в «split value»): ложного утверждения нет (C), а метка 1.
  Замер по всему v2: таких прозовых переименований 975/3876 (25,2%
  переименований, 3,3% синтетики) — известный шум; решение (ужесточить
  rename до documented-only, раунд 5) — за пользователем.
- Тесты: **80 passed** (+7 новых: всегда-is-None, promotion,
  no-match→None, 2 отсева removed, правила путей, фильтр путей).
