# FD-39: слепая R9-разметка полного Go-набора (full381, 381 кейс: gin + cobra)

Тебе прислан один шард `go_batchNN.prompt.txt` (10-12 кейсов:
подмножество `data/processed/go_full381.csv`, всего 381 строка go000…go380,
репо gin + cobra). Размечай КАЖДУЮ строку независимо. Меток (включая прокси
`doc_changed` из sidecar) ты не видишь — и не пытайся их угадать: решай только
по диффу и godoc. Sidecar `go_full381_sidecar.json` тебе НЕ показывают.

Прогон независимый: не смешивай ответы с другим прогоном; один шард —
один контекст целиком, не размечать по частям в разных сессиях.

## Вход строки
- `id` — идентификатор пары (go000…go380), его же вернуть в ответе;
- `file`/`symbol` — файл и функция/метод (вид `Recv.Name` — метод с ресивером);
- `sig_old` — заголовок `func …` ДО (у методов — с ресивером в скобках);
- `diff_code` — unified diff полного текста объявления (с телом, БЕЗ godoc);
- `doc_old` — godoc-комментарий (`//…`) ДО изменения.
Больше ничего не видно — код вне диффа не додумывать. Go-специфика:
документируется экспортируемое поведение; однострочный godoc — полноценное утверждение.

## Шкала R9 (вопрос: «нужно ли обновить godoc из-за этого изменения?»)
- **A. Нужно обновить** — хотя бы одно утверждение godoc стало НЕВЕРНЫМ
  (имя/назначение параметра, поведение, возвращаемое значение, условие ошибки).
- **B. Желательно обновить** — ничего неверного нет, но изменение добавило важную
  возможность/условие, которых нет в godoc.
- **C. Актуально** — все утверждения остаются верными и полными.
- **D. Не могу решить** — нужен контекст вне диффа и godoc (указать какой в `why`).
  Доля D < 10%.

**Жёсткое правило: если в godoc нет утверждения, ставшего ложным, — НЕ A.**

## Как размечать (≤ 2 минут на строку)
1. Выписать проверяемые утверждения godoc.
2. Найти для каждого соответствующий фрагмент диффа.
3. Есть конкретное ложное утверждение → A; неверного нет, но появилось важное → B; иначе → C.
4. Сомнение A/B → B; B/C → C (и поясни в `why`).

## Формат ответа (строго, CSV)
ОДИН CSV-блок, заголовок строго:
id,label,stale_statement,why
- `label` ∈ {A,B,C,D}; строк столько же, в том же порядке, что кейсы;
- `stale_statement` — точная подстрока `doc_old`, ставшая ложной (только для A,
  иначе пусто). Цитируй посимвольно — проверяется автоматически;
- `why` — одна фраза (для D — какого контекста не хватило).
