# FD-08: статистика synth_ast (R6, максимум: 6 pos + 3 neg)

- Команда: `python scripts/generate_synth_ast.py --seed 42 --max_pairs 30000`
- Вход: `data/interim/functions_pool_v1.parquet` (1474 функции, 91 проект, только train_pool)
- Выход: `data/interim/synth_ast.parquet` — **7367 пар** (pos 3803 / neg 3564)
- `pair_id` уникален; проектов 91 (утечек test-пула нет — наследуются из пула v1)
- Порядок проб типов: pos — rare-first (`default_changed`, `return_changed`
  первыми, остальные в случайном порядке, без повторений); neg — выборка типов
  **с возвращением** (функция может дать несколько пар одного типа, разные сиды →
  разные диффы); условия применимости НЕ ослаблялись
- Контроль качества ревью: обязательный `ast.parse(code_new)` в драйвере;
  `param_removed` — только документированные параметры, неприменим при перезаписи
  в теле (только Load-замены), при чтениях без дефолта (нечем заменить) и при
  вызовах/атрибутах/индексах от None;
  `change_message` только внутри print/logging/warnings.warn и raise;
  `return_changed` неприменим при уже nullable-аннотации;
  `default_changed` — имя словом + слово default в окне 3 строк (без value-ветки);
  `exception_changed` — замена типа только для задокументированных типов.
